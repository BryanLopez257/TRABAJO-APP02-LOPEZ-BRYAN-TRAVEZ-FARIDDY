# 🏥 Medicity - Sistema Médico Distribuido

    Aplicación distribuida para la gestión de un sistema médico, desarrollada como proyecto académico de la materia **Aplicaciones Distribuidas**.

    **Autores:** López Bryan & Trávez Fariddy

    ---

    ## 📁 Estructura del Proyecto

    | Carpeta | Descripción | Tecnología |
    |---------|-------------|------------|
    | `FLUTTER APP_02_FARY_BRYAN` | Aplicación móvil/web (Frontend) | Flutter / Dart |
    | `app_02 API` | API REST (Backend) | ASP.NET Core / C# |

    ---

    ## ⚙️ Funcionalidades

    - 📋 **Consulta General** — Vista general de registros médicos
    - 👥 **Gestión de Pacientes** — Crear, editar y consultar pacientes
    - 🩺 **Gestión de Doctores** — Registro y administración de doctores
    - 🏷️ **Especialidades** — Catálogo de especialidades médicas
    - 📅 **Citas Médicas** — Programación y gestión de citas
